# Documentation

GitHub wikis are unavailable on private repositories under a free organization plan, so
these pages serve that purpose. They are ordinary Markdown in the repository, which has
two advantages over a wiki: they are versioned with the code, and they can be reviewed in
a pull request. If the repository is made public on publication, the wiki becomes
available and these pages can be moved there — or simply left here.

| Page | Contents |
|---|---|
| [`data-access.md`](data-access.md) | Which archive holds what, and how to get it |
| [`known-issues.md`](known-issues.md) | Caveats you must know before running the code or reading the tables |
| [`faq.md`](faq.md) | Questions we expect |
