# Experimental measurements and normalization

| Assay or figure panels | Reference or loading control |
|---|---|
| RT-qPCR, including Figure 3C | Gapdh |

The Figure 3D loading control and all five Figure 3E protein ratios use α-tubulin. Supplementary Table S3 identifies the corresponding rabbit antibody as α-tubulin (Thermo Fisher, catalog 600-401-880).

The Prism projects contain the reported normalized measurements and statistical analyses. Data S1 contains the normalized inhibitor measurements, and Data S2 contains the corresponding ANOVA and Dunnett comparisons. These tables are regenerated from the declared Figure_3.prism data sheets. The original representative blot-image deck is included in the data archive as WesternBlotRawImages.pptx.
