# Reproduction and interpretation limits

The primary FASTQ-to-DESeq2 workflow is described but is not independently executed here. The saved RUVSeq/DESeq2 objects and exact processed inputs permit inspection of the reported model; current reproduction starts from these archived results. Figure S3's complete R/Seurat rerun and Figure S5's full/regional BAM extraction passed the 2 October audit. Their exact environment and required original records are now declared in the repository/data snapshot.

Provider-filtered reads are the rawest files returned. Unfiltered instrument reads, raw qPCR Ct values and raw band-intensity inputs have not been reconstructed. The September normalized PZFX files support the reported inhibitor ANOVA/Dunnett exports. Matching full uncropped gels/blots and conflicting p38/loading-control/primer records remain author/source items.

Bulk reference fractions do not establish cell autonomy or lineage conversion. TPM/CPM differ in scale and the P7 incisor reference is not stage-matched molar tissue. Deconvolution t-test P values are descriptive and uncorrected. Program tests have an exact permutation floor of P=0.10. Gene-level DESeq2 significance must be distinguished from those program tests. Sox2/Lgr5 have low auxiliary counts without retained gene-level model tests; mixed-sex pooled libraries and sex-linked program genes remain possible confounders.

The source-workbook dimension defect is handled by direct worksheet XML parsing. Very small adjusted P values require pandas round-trip parsing. Zero adjusted P values are numerical underflow; missing values are not zero. Marker sets are sorted before NNLS fitting so iteration order is deterministic. Table S1 documents the superseded list's provenance audit; it is not used as the active enrichment gene set.

All retained analyses run without data downloads after acquiring the matching code/data and installing the declared software. This does not place large study data inside Git. The local data snapshot still needs live-record synchronization; access remains restricted during review. Computational figure content is reproduced, while UMAP geometry/font rendering and PDF bytes may vary across systems.
