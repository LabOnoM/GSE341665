# Data access

The study uses [GEO GSE341665](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE341665) for provider-filtered sequencing files and complete count/TPM matrices, [Zenodo 10.5281/zenodo.21637766](https://doi.org/10.5281/zenodo.21637766) for the manuscript's processed inputs/model objects, and this repository for code. The [interactive report](http://smad4kotooth.nexitia.ai/) supplies historical primary-analysis context. The external [GSE146855](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE146855) reference is public.

GitHub was authenticated as private on 2 October 2026; unauthenticated HTTP 404 is expected for a private repository. GEO public requests encountered a browser challenge and Zenodo returned HTTP 403, so these requests did not authenticate deposit contents or release status. Confidential deposit credentials are supplied to the journal separately. Contact the corresponding authors for code access during review. No secret link or credential belongs in this repository.

The staged Zenodo record has been cleaned to the latest manuscript scope. Updating an existing published record may require a new version; the local cleanup does not alter the live Zenodo record. The data upload must match `data/INPUT_MANIFEST.json` before reuse. The existing data DOI is not a code DOI. No code DOI has been minted by this preparation.

The staged experimental sources include unchanged `Figure_2.prism`, `Figure_3.prism` and `WesternBlotRawImages.pptx`. Data S1 and S2 remain open CSVs in `07_latest_results/` in Zenodo and `results/inhibitor_data/` in this repository. These are repository source data rather than separate journal supplements; the numbered Additional files are now 1–7. The live-record update must include both the computational inventory and the separately retained experimental sources in `RAW_EVIDENCE_MANIFEST.json`.

The current package excludes duplicate inhibitor PZFX files. Figure_3.prism supplies the declared inhibitor tables for execution; the 70-input computational manifest overlaps the experimental-evidence inventory at this project. The total retained data inventory is 72 unique files. CSV provenance identifies Figure_3.prism and native sheet titles.
