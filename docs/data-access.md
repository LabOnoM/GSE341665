# Data access

The study uses [GEO GSE341665](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE341665) for provider-filtered sequencing files and complete count/TPM matrices, [Zenodo 10.5281/zenodo.21637766](https://doi.org/10.5281/zenodo.21637766) for the manuscript's processed inputs/model objects, and this repository for code. The [interactive report](http://smad4kotooth.bs-gou.com/) supplies historical primary-analysis context. The external [GSE146855](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE146855) reference is public.

GitHub was authenticated as private on 2 October 2026; unauthenticated HTTP 404 is expected for a private repository. GEO public requests encountered a browser challenge and Zenodo returned HTTP 403, so these requests did not authenticate deposit contents or release status. Confidential deposit credentials are supplied to the journal separately. Contact the corresponding authors for code access during review. No secret link or credential belongs in this repository.

The staged Zenodo record has been cleaned to the latest manuscript scope. Updating an existing published record may require a new version; the local cleanup does not alter the live Zenodo record. The data upload must match `data/INPUT_MANIFEST.json` before reuse. The existing data DOI is not a code DOI. No code DOI has been minted by this preparation.
