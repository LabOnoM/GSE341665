# Questions, corrections and reuse

Report a problem with the exact manuscript panel/table, expected and observed values, repository commit, command, environment and input-manifest version. During restricted review, contact the corresponding authors for repository access. Repository issues may be used by people who already have access; do not post confidential tokens or patient/animal identifiers.

Code retains the existing MIT licence. Cite the manuscript and exact code commit, and cite the separate data DOI for the data. Main archived-result and supplement modes use the captured inputs and need no runtime downloads. Optional reference reannotation and panel refresh require the documented external sources. Keep the pinned panel and recorded analysis version when reproducing the paper. Read very small adjusted P values with pandas round-trip parsing and preserve missing/source-zero states.
